Primary, secondary, ghost, danger and disabled buttons in uppercase Chakra Petch.

**Maps to:** SwiftUI `Button` styles used across MilestoneView (Keep Going, Share), RepeatLastButton, settings actions.

**Consumer provides**
- `label`, `variant`, `action`.

**Do**
- One primary per screen.
- Danger is outlined with a word; never a red fill alone.

**Don't**
- Don't use the brand gradient on buttons (LogButton only).

**Tokens:** `accent`, `on-accent`, `line-strong`, `danger`, `surface-alt`, `focus`, `radius-md`, `tab`.
