## C. On-device verification (Jay drives, Claude debugs)

Run against **TestFlight build 2**, since that uses Production CloudKit like testers' builds do.

**C1. Two-device iCloud sync** (two devices, same Apple ID):
- [ ] Log an activity on A → it appears on B without relaunching (tests the production `aps-environment` silent push).
- [ ] Delete an activity on A that drops a total below a milestone → the badge disappears on A, then on B.
- [ ] Fresh install on B with existing data → totals are **not** inflated (validates removing the v1.2 migration) and badges are **kept** while sync catches up (validates the reconcile fix).
- [ ] Earn the same badge on both devices while offline, then reconnect → only one badge shows (validates dedupe).

**C2. HealthKit:**
- [ ] Grant permission; walking, running, hiking, and cycling workouts import and count toward distance.
- [ ] A manual entry within about ±1 h / ±5% of an imported workout is not double-counted.
- [ ] Write-back: a manually logged distance appears in the Health app and isn't imported back.
- [ ] Note: imported workouts unlock badges silently (no celebration screen). See F2.
