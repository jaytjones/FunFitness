All LOOSE/WRONG rows above were fixed in one commit, with these deviations from the suggestions:

- **Dinosaurs weight** was rebuilt as one chain by sourced mass: W2 Kentrosaurus → W2b Styracosaurus →
  W3 Stegosaurus → W3b T-Rex → W4 Triceratops → W4b Apatosaurus (unchanged) → W5 *Diplodocus hallorum* →
  W5b Giraffatitan → W6 Brachiosaurus.
- **Animals D9** uses "two full laps of the great wildebeest migration" (consistent with D8's
  NatGeo lap) instead of the mountain-lion news story, which wasn't independently verified.
- **`animals.wildebeestMigration`** is set to 800 km (NatGeo's ~500 mi round trip) to match the D8 copy,
  rather than the suggested 900 km.
- Also applied: Statue of Liberty 204,000 kg, the NYC Marathon / Eiffel build / corn kernels / Eiffel
  height wording, and the 🏛️ emoji for Marathon to Athens.

Still open: the VAGUE rows (by design), duration/reps comparisons (unchecked), and the distance
spacing gaps in Animals, Dinosaurs, and Food.
